# Security Notes

This is a low-risk practice-test MVP, not a proctored exam platform. Answers and score calculation are delivered to the browser and are inspectable, so client results must not be trusted for certification, recruitment or other high-stakes decisions.

This version does not collect personal information, create accounts, store scores, use analytics, or send quiz data to an external service. If these features are added later, implement consent and privacy documentation, server-side validation, access controls, and an appropriate retention policy.

Do not commit API keys, passwords, or private user data.
